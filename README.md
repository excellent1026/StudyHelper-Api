# StudyHelper-Api 自习助手后端
> 医药相关学习辅助后端项目（SpringBoot3 + MyBatis-Plus）

## ✨ 项目介绍
面向医药学习场景的后端接口服务，支持用户、文档、学习资料管理，提供基础CRUD接口，适配小程序前端。

## 🛠 技术栈
- Spring Boot 3
- MyBatis-Plus
- MySQL 8
- Maven 3.9.11
- Knife4j 接口文档

## 📦 环境要求
- JDK 17+
- MySQL 8.0
- Maven 3.9.11
